# The repositories to fix. One per line. How-to: repos/README.md
#
#   <name>  <git-url>  [branch=<b>] [path=<subdir>] [smoke=true] [build="<cmd>"]
#
#   name    folder it's cloned into: repos/<name>/   (letters, digits, . _ - only)
#   git-url the URL you'd give `git clone` (HTTPS or SSH)
#   branch  the repo's main branch, if it isn't called `main`
#   path    sub-folder that holds pom.xml / build.gradle  (default: the repo root)
#   smoke   also start the app during verification and wait for "Started ... in"
#   build   your own build command  (default: ./mvnw -B clean verify  or  ./gradlew clean build)
#
# Every repo is cloned into repos/<name>/ and the changes happen there, on branch deps/wf-NNN
# (one branch per workflow, from the latest main). Your own checkouts elsewhere are never touched.
# Have it checked out already? `repos.py add ~/path/to/it` finds its URL for you.
#
# Then:  python3 -I toolkit/scripts/repos.py clone        (or /dep-clone, or just /dep-run <name>)
