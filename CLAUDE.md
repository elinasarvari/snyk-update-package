# snyk-update-package

This is a **meta repository** for Snyk-driven dependency upgrades. It has no application code of its own.

- Target repos are listed in `repos/repos.txt`, each as a **local folder** (the user's own checkout, used in place)
  or a **git URL** (cloned into `repos/<name>/`, git-ignored). `repos.py list` gives each one's `repo_dir`.
  Code changes happen **only** in those repo folders, on `deps/<upgrade-id>` branches, through the `/dep-*`
  commands. This project never stores their code or changes.
- The workflow is defined in `workflow/`: `WORKFLOW.md` (overview), `phases/`, `roles/`, `templates/`,
  `scripts/`. Agent and prompt files in `.github/` are generated by `tools/generate-entrypoints.py`.
  Edit `workflow/`, not the generated files.
- Each upgrade is documented in `upgrades/<YYYY-MM-DD>-<slug>/`, starting from `STATUS.md`.
- Never commit, push or open PRs in a target repo outside `/dep-publish`. Never reset, stash or switch
  branches in a clone with the user's changes. Never skip or disable tests.
